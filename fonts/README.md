# Local appearance fonts

Downloaded from the Google Fonts CSS2 API on 2026-09-09. Each family retains its
SIL Open Font License in LICENSE-<family>.txt, from google/fonts on GitHub.
Binary font data is unmodified. The hash in each filename identifies its source URL.
Latin and Latin Extended subsets cover the authored site text; other scripts use
system fallbacks. `fonts.css` retains each subset’s Unicode ranges and uses swap.

Families: Source Serif 4 (400), IBM Plex Mono (400/500/600), Newsreader (400–600),
DM Sans (400–700), Montserrat (400–600), Courier Prime (400/700), VT323 (400),
Fira Mono (400/500). Georgia is a system font and requires no download.

The homepage and coffee page link the shared definitions. Browsers request only
the font files used by the chosen appearance; there is no background preload of
other styles. Non-generative pages retain their existing font loading.
